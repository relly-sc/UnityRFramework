# 可选扩展参考

核心包与 Samples 包分离。先确认 `com.relly-sc.unityrframework.samples` 已安装且版本与核心包一致，再确认目标 Sample 已导入宿主项目；`Package.json` 的 `samples` 列表和 Sample 自带 README 是当前版本的安装、依赖、菜单和验收依据。

| 想做什么 | 导入/核对 |
| --- | --- |
| YooAsset 资源更新、地址加载和 Bundle 可选加密 | `Expansion.YooAsset`，项目需先安装 YooAsset；完整流程参考 `Expansion.YooAsset.Demo`。 |
| HybridCLR 热更代码 | `Expansion.HybridCLR`，项目需安装并初始化 HybridCLR；完整闭环再看 `Expansion.HybridCLR.Demo`。 |
| Obfuz 混淆热更程序集 | `Expansion.Obfuz`，需 Obfuz 与 Obfuz4HybridCLR；Obfuz Settings 是配置事实源。 |
| Excel 配置与本地化导出 | `Expansion.ExcelDataReader`；核心 CSV 工具不依赖它。 |
| UI 绑定、检查、图集、红点等 | `Expansion.UI`；`Expansion.UI.Demo` 只提供示例和验收。核心 UI 可独立使用。 |
| UniTask Web 请求 Helper | `Expansion.UniTask`，项目需安装 UniTask。 |
| ZIP/RAR/7z 等压缩包解压 | `Expansion.SharpZipLib` 或 `Expansion.SharpCompress`，按格式需要选择，不要同时默认接入。 |
| 存档平台密钥仓 | 对应的 `Expansion.Security.Windows/Android/iOS/macOS`，按目标平台导入并验证。 |

## 资源与加密边界

- YooAsset Helper 替换资源来源，但业务仍通过 `GameEntry.Resource` 加载和归还。Host 模式需要可访问的清单、版本和 Bundle；EditorSimulate 成功不等于 Player 发布成功。
- Config 加密与 YooAsset Bundle 加密可以叠加，密钥独立。已有密钥首次生成后应复用；主动更换密钥会使旧加密产物及缓存失效，不能在普通升级时随意重生。
- 当前默认密钥文件分别是 `Assets/Resources/UnityRFramework/ConfigKey.bytes` 与 `Assets/Resources/UnityRFramework/YooAssetKey.bytes`，运行时通过 Resources 自动读取。不要将它们迁入需要该密钥解密的 Bundle；存档的安装级 `SaveKey` 属于另一套密钥管理。
- HybridCLR 的 `IHotUpdateEntry` 是框架/扩展的入口契约，`EntryTypeName` 填实现类型的完整名称；它不是 HybridCLR 插件通用设置。新热更 DLL 已在当前进程加载后，软重启不能替换它。
- 扩展 README 只描述该扩展，不代表核心包自动集成或自动安装第三方依赖。用具体项目的 asmdef、Package Manager 与 Inspector 状态确认后再给出代码。
