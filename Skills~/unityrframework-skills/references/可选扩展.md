# 可选功能与扩展选型

## 先确认可用性

核心包与 Samples 包分离。先核对当前 com.relly-sc.unityrframework.samples 的版本、samples 清单、已导入目录与第三方依赖。扩展源码/README 和业务 asmdef 是实际依据；不把“仓库有文件”当作“消费项目已安装功能”。

优先使用核心菜单“安装扩展与示例”，先安装当前框架固定版本的 UPM 依赖，再导入扩展与 Demo。
固定版本与依赖图以核心 `Scripts/Editor/FrameworkSamples.json` 为准；不自行安装最新版，
不修改核心 asmdef 引入第三方引用。已有不同版本要先征得更换同意，本地或嵌入式插件不能自动覆盖。
R3 的 NuGet 本体、Obfuz 生成代码及密钥、HybridCLR Installer 初始化不是 UPM 安装成功的证明。
升级后同步已导入的扩展源码前，先备份用户修改；原生 Package Manager Import 不经过此检查。

本文件负责何时选择扩展和容易越界的地方；具体调用先查当前扩展 README 与 Runtime/Editor 源码。业务仍遵循 [业务脚本规范](业务脚本规范.md)，并尽量通过核心 GameEntry 契约调用后端能力。

## 功能地图

| 需求 | 选择与边界 |
| --- | --- |
| 包版本、远端资源更新、YooAsset Address、Bundle 保护 | Expansion.YooAsset，先安装其要求版本的 YooAsset；需要完整更新过程再看 Expansion.YooAsset.Demo。 |
| 已发布客户端更新 C# 业务程序集 | Expansion.HybridCLR，先安装并初始化 HybridCLR；完整闭环看 Expansion.HybridCLR.Demo。 |
| 可选 IL2CPP/热更代码混淆 | Expansion.Obfuz；联合热更需其说明要求的 Obfuz4HybridCLR，不把混淆当资源加密。 |
| XLS/XLSX 作为配置或本地化来源 | Expansion.ExcelDataReader；运行时仍用核心 Config/Localization，不创建第二套读取模块。CSV 工具在核心，不要求 Excel 扩展。 |
| UI 自动绑定、检查、图集、Safe Area、弹窗/Toast、虚拟列表、红点、长按/双击 | Expansion.UI；这些不是核心 UI 的必备依赖；示例资源在 Expansion.UI.Demo。 |
| UniTask Web 请求 Helper | Expansion.UniTask，项目需已安装 UniTask；核心使用 Task，不把项目所有异步方法强行改为 UniTask。 |
| 响应式数据、事件组合、防抖和持续 UI 更新 | Expansion.R3，需 R3 本体及 R3.Unity；与 UniTask 分工，不替换核心 Event/Timer，也不要求 MVVM。示例在 Expansion.R3.Demo。 |
| Zip64/加密 ZIP | Expansion.SharpZipLib；只有无密码 ZIP 时核心默认解压已够用。 |
| RAR/7z/TAR 等其他压缩格式 | Expansion.SharpCompress；按实际格式选，不同时默认接入两套解压器。 |
| Windows/Android/iOS/macOS 系统存档密钥保护 | 对应 Expansion.Security.*，用于 Storage 安装级 SaveKey，不是 ConfigKey 或 YooAssetKey。 |
| 核心模块独立示例 | Sample.UI、Sample.Storage、Sample.Download；不应把示例框架根节点与宿主已有根节点一起复制进场景。 |
| 普通内存数值与保护数值对照 | Sample.Security，是否可导入以当前 samples 清单为准；不将扫描不到数值夸大为不可破解。 |

相机、跨程序启动、字符串 Messenger、Runtime/XR 小工具等也先检查当前包是否真的提供/已导入。开发源码中的 Sample.Camera、Sample.Messenger、Expansion.Platform.Windows 等名字不能替代消费包清单。它们不是 GameEntry 核心模块，不推导出 GameEntry.Camera/Messenger/Platform。

## YooAsset

- **何时用**：需要远端资源更新、分包、Address 或 Bundle 保护；纯本地 Resources 已够用时不强制升级。
- **流程/模式**：核对 Resource Helper、Package 名称、模式和服务器；用扩展现有初始化/更新流程准备版本、清单和 Bundle，再让 Config、UI、Entity、Audio 通过 GameEntry.Resource 链路消费。
- **生命周期**：框架/Helper 管理的句柄按其所有权处理，业务直接加载引用仍需归还；不要再用 YooAsset 裸句柄与框架各加载一遍同一资源却只释放一次。
- **误用**：EditorSimulate 成功不证明 Host/Player 正确，Windows 产物不是 Android 产物。核对收集器、实际 Address、发布目录和缓存，不照抄 Demo 服务器路径。
- **查询**：实际 Expansion.YooAsset 的 README、YooAssetResourceHelper 与 Bundle 保护实现；示例为 Expansion.YooAsset.Demo。

## HybridCLR 与 Obfuz

- **何时用**：确需运行时更新代码才导入 HybridCLR；确需增加逆向成本才启用 Obfuz。无热更的项目不默认改后端或生成 AOT 基线。
- **流程/模式**：遵循当前扩展 Player 准备、基线、热更产物、收集和发布链路。用户选择联合混淆时核对 Obfuz4HybridCLR 与生成步骤，不猜菜单或重建次数。
- **入口**：EntryTypeName 是框架的 IHotUpdateEntry 契约，实现类型填命名空间加类名，不是外层加载脚本或 HybridCLR 的通用配置。
- **生命周期**：新 DLL 已加载到进程后，框架软重启不能卸载替换该程序集；验证新版本须按扩展流程真正重启 Player。
- **误用/查询**：反射、序列化、字符串入口和持久化事件在 IL2CPP/混淆下须验证。查当前 Expansion.HybridCLR/Obfuz 的 README、配置资产和步骤；Settings 与实际产物是事实源，不因为有 symbol-mapping 就声称全部平台可运行。

## Excel 与配置工具

- **何时用**：源表确为 Excel 时选 ExcelDataReader；已有 CSV 流程不强行迁移。
- **流程/模式**：按当前工具 Schema、逻辑表与分片规则导出行类型、Codec、Config/Localization；运行时解析仍属于核心模块，地址和保护设置与构建步骤一致。
- **生命周期**：生成文件与产物是一套契约，不能只复制生成 C# 或只发二进制；自定义字段 Codec 按规定在导出与运行时读取前注册。
- **误用**：Static Text/TMP 键检查可验证已导出键；动态拼接键不能可靠静态推断。ReservedKeys.txt 放对应工具设置的 Localization 源目录，不默认丢到 Assets 根目录。正式构建不通过删除多语言/Config JSON 来隐藏错误。
- **查询**：核心 ConfigPipeline/ConfigEditorWindow 与当前 Excel 扩展 README/Editor 实现；核对当前窗口按钮而不是旧菜单截图。

## UI 工具与组件

- **何时用**：重复绑定、预制体检查或通用交互确有需求时导入 Expansion.UI；普通窗口加载和栈管理仍由核心 UI 提供。
- **绑定流程**：选业务节点和明确的目标 MonoBehaviour/组件类型，业务类声明 partial，生成并回填 .Bindings.g.cs；业务在自己的 partial 文件实现回调，不编辑生成文件。
- **生命周期**：序列化引用和生成的持久化 UnityEvent 已有绑定，不再追加同一套 AddListener；业务自行添加的监听则自行移除。TMP 强类型字段需要业务程序集真实引用。
- **组件选择**：安全区域用 Safe Area；大列表用固定高度虚拟列表并验证复用状态；红点数来自项目规则，树负责路径聚合/展示；长按/双击使用现有组件；静态语言文案优先核心 LocalizedText，不重复写语言订阅。
- **误用**：非交互 Text/Image 不应臆造 UnityEvent；独立 Canvas、输入系统、Raycast 和实际渲染顺序仍由项目配置。UGUI Inspector 成功不证明 Obfuz/IL2CPP 的持久化事件成功。
- **查询**：当前 Expansion.UI README 的对应章节和工具/组件类；Expansion.UI.Demo 只提供示例，不是运行时模块依赖。

## R3 响应式业务

- **何时用**：需要持续观察数据变化、组合条件、过滤事件或搜索防抖。普通单次事件和异步加载不必引入 R3。
- **流程**：查当前 Expansion.R3 README。`GameEntry.Event.Observe<T>()` 返回冷事件流，订阅时接入，Dispose 时退订；不创建第二套框架事件总线。
- **生命周期**：可选继承 `R3UIFormLogic`，在 `OnOpenWithR3` 绑定并 AddTo `OpenSubscriptions`，关闭自动释放；实体对应 `R3EntityLogic`、`OnShowWithR3` 和 `ShowSubscriptions`。已有业务基类不便替换时直接成对管理 CompositeDisposable，不强改继承结构。
- **误用**：不要只在 OnDestroy 清理会关闭/复用的对象；共享 ReactiveProperty 由数据拥有者管理。异步任务取消与释放订阅是两件事；软重启后从新组件重新绑定。缺少 R3 DLL 或适配包时先报告依赖，不修改核心 asmdef 来解决。
- **查询**：EventObservableExtensions、R3UIFormLogic、R3EntityLogic；交互示例为 R3DemoController、R3DemoForm。

## 平台密钥仓与其他工具

- **何时用**：Storage 已选择安装级加密且需要系统保护密钥时才导入对应平台扩展；不自动全部导入。
- **流程/模式**：核对目标平台、Helper/平台工厂、Inspector 的保护与自动管理选项；读取 Storage 的实际密钥仓类型和错误，再区分 Editor 替代实现与 Player 原生实现。
- **生命周期**：存档备份不能替代密钥备份；卸载、清数据或身份变化后的行为按平台与项目策略验证。不要为读取失败无授权清理正式存档或系统密钥仓。
- **其他能力**：WebGL 模板查核心 Scripts/Editor/Tools/WebGL，ReadOnly 是只读 Inspector 提示；相机和平台小工具查实际导入代码，不认为它们天然跨平台或属于核心模块。
- **查询**：当前 Expansion.Security.* README 与实现，或实际 Sample/Editor 工具源码；发布包未提供的能力应说明缺口，不能编造安装入口。

## 内容保护边界

Config 加密与 YooAsset Bundle 加密可以叠加，密钥独立。默认内容密钥文件为 `Assets/Resources/UnityRFramework/ConfigKey.bytes` 与 `Assets/Resources/UnityRFramework/YooAssetKey.bytes`，运行时从固定 Resources 位置自动读取；不要把它们移入需要自身密钥才能读的加密包。已有密钥普通升级复用，主动更换才重新导出并按客户端兼容策略发布。

Storage 的 SaveKey 属于安装级管理，不与上述随 Player 发布的内容密钥混用。三层可选保护不意味着强保密、无法逆向或已完成全部设备验收。
