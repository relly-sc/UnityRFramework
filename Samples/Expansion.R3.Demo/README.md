# R3 响应式交互示例

## 运行

1. 按 `Expansion.R3/README.md` 安装 R3 本体和 R3.Unity，导入 `Expansion.R3` 与 `Expansion.R3.Demo`。
2. 选择 `UnityRFramework → Expansion → R3 → 打开响应式交互示例`。若场景尚未生成，会自动生成；已有场景需要更新时选择“生成响应式交互示例”，覆盖前会确认。
3. 点击 Play。场景包含框架入口、Camera、EventSystem 和中文 UGUI，不需要手动接按钮或创建 Canvas。

生成器从自身脚本查找当前导入位置，支持开发目录与 Package Manager 的版本化 Samples 目录，不写死版本号。生成过程不会保存、丢弃或关闭用户当前场景；打开示例前会询问未保存场景。

## 操作与预期

| 操作 | 预期 |
| --- | --- |
| 初次运行 | 界面已打开，事件订阅为 1，积分为 0，领取按钮不可用。 |
| 点击三次“积分 +1” | 积分为 3，界面即时刷新，勾选“允许领取”时可领取。 |
| 取消“允许领取”再勾选 | 积分不变，领取按钮随条件变化。点击领取消耗 3 积分。 |
| 快速连续输入搜索词 | 停止输入约 0.35 秒后结果刷新，连续输入合并处理。 |
| 点击“发送框架事件” | 发送和收到各增加 1，最近事件更新。 |
| 关闭界面后继续发送 | 事件订阅为 0，发送增加，收到不增加。 |
| 关闭时点击“积分 +1”，再打开 | 重新打开显示最新积分；事件订阅恢复为 1。关闭时发送的事件不会重放。 |
| 连续开关多次再发送一次 | 收到只增加 1，不重复回调；示例复用同一个场景 UI 对象。 |
| 点击“重置数据” | 积分、发送及收到计数清零。 |

界面较小可纵向滚动；输入关键词长度限制为 80，结果不会向屏幕外无限堆叠。数据由 `R3DemoController` 持有，`R3DemoForm` 只持有本次打开的订阅。

## Player

将实际生成的 `GameAssets/Scenes/R3Demo.unity` 加入构建场景并启用，再按项目需要构建目标平台。Demo 无资源服务器、密钥或 Config 要求，不依赖 UniTask、YooAsset 或 HybridCLR。Editor 编译及测试不代表所有 Player 平台通过；使用 IL2CPP、WebGL 或混淆时仍需在实际配置下运行验证。

## 自动检查

退出 Play Mode 后选择 `UnityRFramework → Expansion → R3 → 检查事件与订阅清理`。通过时控制台显示 `8/8 项通过`。检查与生成工具都随宿主编入默认 Editor 程序集，不为普通扩展、Demo 或检查脚本创建 asmdef。
